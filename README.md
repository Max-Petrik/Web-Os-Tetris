Beschreibung:

Bei meinem Projekt handelt es sich um einen simplen login, welcher mit einem Tetrisspiel verknüpft ist.
Als Eingabe für den Login wird der Vorname, Name und die Email abgefragt.

Bei dem Spiel muss man um es steuern zu können einmal in die Website klicken, da das Tetrisspiel selbst als iframe eingebunden ist.

Die Daten können dann im Profil abgerufen werden.
In das Profil kommt man jederzeit über den Button Profil nach dem Login.
